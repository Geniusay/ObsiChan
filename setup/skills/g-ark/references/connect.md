# Connect Mode

Use connect mode to improve navigation between existing knowledge objects or to create a requested MOC.

## Workflow

1. Load [write-safety.md](write-safety.md), the canonical schema, and current taxonomy/MOC policy.
2. Inspect the note, candidate targets, existing backlinks, and the closest MOCs.
3. Add only relationships that help a future question, comparison, decision, project, or output.
4. Prefer an existing specific MOC over a broad or newly created map.
5. Place links in the receiving document's existing structure; do not duplicate note summaries or reorganize unrelated sections.
6. Add reciprocal links only when they improve navigation and conform to system policy.
7. Create a new MOC only when explicitly requested or when current policy clearly authorizes it and the topic has enough durable material.
8. Validate links and report the exact connections made.

## Boundaries

- Similar topic labels do not automatically justify a link.
- Do not use MOCs as exhaustive indexes or replace hierarchy with link volume.
- Do not introduce a new taxonomy term as a side effect of connecting notes.
- If several targets are plausible, present the high-signal choices instead of guessing.
