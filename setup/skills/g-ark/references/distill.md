# Distill Mode

Use distill mode when the user wants external material converted into traceable, reusable knowledge rather than only stored.

## Workflow

1. Load [write-safety.md](write-safety.md), the canonical schema, and the current source-processing policy.
2. Read the source completely enough to distinguish its claims from commentary and from the user's views.
3. Search by source identity and by each candidate idea before creating anything.
4. Create or update the source note according to the canonical schema. Keep its account attributable to the source.
5. Extract only ideas with standalone future value. Use the smallest useful set; creating zero extracted notes is valid.
6. Reuse an existing knowledge note when it expresses the same idea. Add provenance or a relationship without erasing the user's formulation.
7. Mark AI authorship and review state exactly as the schema requires. Keep uncertainty and evidence visible.
8. Run `connect` only for clearly relevant existing maps, or when the user explicitly asks for a new MOC.
9. Validate changed notes and report source notes, extracted notes, reused notes, connections, and review needs separately.

## Quality Bar

- A source note answers what the material says; a knowledge note captures a reusable understanding or claim.
- Do not inflate a weak source into many small notes.
- Keep quotations short and traceable. Never convert inference into an attributed fact.
- Do not create a new MOC merely because a new topic label appeared.
